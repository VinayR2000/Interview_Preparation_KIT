# 45. Internationalization (i18n)

---

## Theory

Internationalization enables your application to support multiple languages and locales (date/number/currency formatting).

### Angular i18n Approaches

| Approach | Type | Use Case |
|----------|------|----------|
| Built-in i18n (`@angular/localize`) | Compile-time | Static translations, one build per locale |
| ngx-translate | Runtime | Dynamic switching, single build |
| Transloco | Runtime | Modern alternative to ngx-translate |

### Built-in i18n

```html
<!-- Mark text for translation -->
<h1 i18n>Welcome to our application</h1>
<p i18n="@@welcomeMessage">Hello, {{ name }}</p>

<!-- Plural -->
<span i18n>{count, plural, =0 {No items} =1 {One item} other {{{count}} items}}</span>

<!-- Attributes -->
<img [src]="logo" i18n-alt alt="Company logo">
```

```bash
# Extract translations
ng extract-i18n --output-path src/locale

# Creates: src/locale/messages.xlf
# Translate to: src/locale/messages.fr.xlf, messages.es.xlf

# Build for specific locale
ng build --localize
# Or: ng build --configuration=fr
```

### Runtime Translation (ngx-translate)

```typescript
import { TranslateModule, TranslateLoader } from '@ngx-translate/core';
import { TranslateHttpLoader } from '@ngx-translate/http-loader';

// Setup
export function HttpLoaderFactory(http: HttpClient) {
  return new TranslateHttpLoader(http, './assets/i18n/', '.json');
}

// app.config.ts
providers: [
  importProvidersFrom(TranslateModule.forRoot({
    loader: { provide: TranslateLoader, useFactory: HttpLoaderFactory, deps: [HttpClient] },
    defaultLanguage: 'en'
  }))
]

// Usage in template
// {{ 'WELCOME' | translate }}
// {{ 'GREETING' | translate:{ name: user.name } }}

// assets/i18n/en.json: { "WELCOME": "Welcome", "GREETING": "Hello, {{name}}" }
// assets/i18n/fr.json: { "WELCOME": "Bienvenue", "GREETING": "Bonjour, {{name}}" }

// Switch language
this.translate.use('fr');
```

### Locale-Sensitive Formatting

```typescript
import { registerLocaleData } from '@angular/common';
import localeFr from '@angular/common/locales/fr';

registerLocaleData(localeFr, 'fr');

// providers: [{ provide: LOCALE_ID, useValue: 'fr' }]

// DatePipe, CurrencyPipe, DecimalPipe automatically use the locale
// {{ today | date:'long' }} → "15 septembre 2024" (French)
// {{ price | currency:'EUR' }} → "1 234,56 €" (French formatting)
```

## Interview Questions and Answers

**Q1: How do you implement multi-language support in Angular?**
> Two approaches: 1. Built-in `@angular/localize` — compile-time, one build per locale, best performance, uses i18n attribute in templates. 2. Runtime libraries (ngx-translate, Transloco) — single build, dynamic language switching, JSON translation files loaded at runtime. Use built-in for static sites; runtime for apps needing instant language switch.

**Q2: How do you handle locale-specific formatting?**
> Register locale data with `registerLocaleData()`, set `LOCALE_ID` provider. Built-in pipes (DatePipe, CurrencyPipe, DecimalPipe) automatically format according to locale. For runtime switching, re-render components after locale change.
